# proofarc-dev-skills (internal)

Skills for developing ProofArc itself, for the ProofArc team. Customers use `proofarc-skills`.

Install next to it:

```
/plugin install proofarc-dev-skills@proofarc
```

| skill | job |
|---|---|
| `usability-flows` | Usability rules for the platform (`rules.md`, U1–U4). Runs the API flows through MCP with no UI, and lists the UI flows to build as dogfood UI tests. Issue: proofarc/tspc-cloud-platform#570. |

Runs only on dev: project `dog-food-api` (169), environment `dev` (125).
